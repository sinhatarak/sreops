# Golden Kubestronaut Path

**Golden Kubestronaut** is CNCF's highest recognition. It requires every CNCF certification plus the Linux Foundation's **LFCS**, and once earned it is yours for life. The list grows as CNCF adds certifications, so check the [official program page](https://training.linuxfoundation.org/resources/kubestronaut-program/) before you plan.

At the time of writing, that is **15 CNCF certifications plus LFCS**.

## What you need beyond Kubestronaut

You already have the five Kubernetes certifications (CKA, CKAD, CKS, KCNA, KCSA). The rest, grouped by theme:

| Theme | Exam |
|---|---|
| **Observability** | **PCA**: Prometheus Certified Associate |
| | **OTCA**: OpenTelemetry Certified Associate |
| **Networking and mesh** | **CCA**: Cilium Certified Associate |
| | **ICA**: Istio Certified Associate |
| **GitOps and delivery** | **CAPA**: Certified Argo Project Associate |
| | **CGOA**: Certified GitOps Associate |
| **Platform engineering** | **CBA**: Certified Backstage Associate |
| | **CNPA**: Certified Cloud Native Platform Engineering Associate |
| | **CNPE**: Certified Cloud Native Platform Engineer |
| **Policy** | **KCA**: Kyverno Certified Associate |
| **Linux** | **LFCS**: Linux Foundation Certified System Administrator |

## A sensible order

1. **LFCS** to anchor the Linux foundation.
2. **PCA** and **OTCA** for observability, since SRE work depends on them.
3. **CGOA** then **CAPA** for GitOps and Argo.
4. **KCA**, **CCA** and **ICA** for policy, networking and mesh.
5. **CBA**, **CNPA** and **CNPE** for platform engineering.

!!! tip
    Pair each exam with a small real project, such as an Argo CD setup or a Prometheus alert rule. You keep the skill long after the exam.
